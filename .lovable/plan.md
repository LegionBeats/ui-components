1. Fetch the real source from `https://21st.dev/r/dhxwhy/skate-deck-rail` (with the 21st.dev key); if the registry returns placeholder code, pull the real implementation from the public listing.
2. Create `src/registry/components/skate-deck-rail/` with the component file, a `demo.tsx` live preview, and `index.ts` (category: Carousels, original install command kept verbatim, source link and author credit to dhxwhy).

4. Register it in the library list, then do one quick browser check that the demo renders without errors.
